Lapdroid

Turn your laptop into an ultra-low latency Bluetooth keyboard, trackpad, and stylus bridge for Android.
🪟 Windows 10 / 11 📱 Android 8.0+ (S24 Ultra, Pixel, Tablets) ⚡ Offline Bluetooth (RFCOMM) 🛡️ Zero LAN / Zero Internet / Zero Telemetry

✨ Key Features

⌨️ Full Keyboard Forwarding Low-latency hardware keystroke streaming with complete support for Windows shortcuts: Ctrl+A, Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+Z, Ctrl+Y.
✍️ Anchor-based Text Selection Intuitive Shift + Left/Right Arrow selection that expands and shrinks naturally, plus Shift+Up/Down and Shift+Home/End.
💬 Tricky Keys & Chat Modes Native WhatsApp Ctrl+Enter to submit, Shift+Enter for new lines, Tab element navigation, and multi-press Alt+Tab app switcher.
🖱️ High-Precision Trackpad Window overlay cursor engine with 3x default sensitivity (range 1x–5x), dual-finger vertical scrolling, and left/right mouse clicks.
🖊️ Windows Ink Stylus Digitizer Reverse pressure, tilt, eraser tip, and barrel button stylus digitizer designed for Samsung S-Pen and drawing tablets.
🔒 100% Private & Offline Zero Wi-Fi or LAN required. Pure Bluetooth Serial Port Profile (RFCOMM). No cloud servers, no account registration, no telemetry.

🚀 Quick Start Guide (3 Simple Steps)

  1. Pair Bluetooth: Pair your laptop and your Android phone in Windows Settings → Bluetooth & Devices.
  2. Launch Lapdroid on Windows: Run Lapdroid.exe. Press F12 at any time to capture or release mouse and keyboard input.
  3. Configure Android Permissions: Open Lapdroid on Android and grant the required permissions:
    • Bluetooth: To connect and listen over standard RFCOMM Serial Port Profile.
    • Display Over other apps: For the hardware mouse pointer overlay.
    • Accessibility Service & Lapdroid IME: For native typing, navigation, and shortcuts.

⌨️ Hotkeys & Shortcut Reference

Shortcut / Action Function Behavior
F12 Toggle Capture Instantly locks/unlocks laptop mouse & keyboard to Android.
Alt + Tab App Switcher Opens Recents overview on first press; cycles running apps on subsequent presses.
Ctrl + Enter Send Message Instant send in WhatsApp, Telegram, Google Messages, Signal, Slack, Discord.
Shift + Enter New Line / Send Inserts newline (in Always submit mode) or submits (in Newline mode).
Ctrl + A / C / X / V Clipboard & Edit Full Select All, Copy, Cut, and Paste with clipboard synchronization.
Shift + ← / → Text Selection Anchor-based caret expansion/shrinking character-by-character.
Ctrl + Shift + ← / → Word Selection Selects whole words backward or forward.
Windows Key System Navigation Configurable to Home, Recents, or Notification shade.
Esc Android Back Executes standard system Back navigation.

🛡️ Privacy & Security Guarantee

Lapdroid is built with privacy as its primary foundation:

  • No Internet Permission: The Android application deliberately omits android.permission.INTERNET from its manifest. It is physically impossible for the app to access the internet.
  • No Cloud or Analytics: Zero tracking, zero telemetry, zero analytics SDKs, and zero third-party dependencies.
  • Pure Local Bluetooth: All keystrokes, touch events, and stylus pressure values are streamed exclusively over the authenticated local Bluetooth RFCOMM link between your paired devices.
